# ADR1 - Program architecture

## Context
Pyslurm is a workload manager and job scheduler similar in behavior to Slurm. This project has been created for learning purposes to understand how resource scheduling works in heterogeneous computing
environments (Or a computing cluster).

## Decision
We will write a program that accepts bash scripts accepted by Slurm and implements a subset of the Slurm commands. Implementing full compatibility with the Slurm program is out of the scope of this project.
1. `sbactch <job-id>`
2. `squeue -u`
3. `srun <resource-parameters>`
4. `skill/scancel <job-id>`
5. `sacct`
6. `sinfo`
The aforementioned commands will have identical meanings to their Slurm counterparts to the extent possible. 

## Status 
Accepted

## Consequences
This document defines the scope of the project insofar as what the project entails, what works will be performed, and what works will be deferred for, possibly, another project.
